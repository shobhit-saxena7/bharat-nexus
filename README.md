# Bharat Nexus - Enterprise AI Platform

Bharat Nexus is a next-generation, professional-grade multimodal AI web application designed to provide smart reasoning, document analysis, and government scheme assistance. Built with a highly modular architecture, it leverages the power of Google's Gemini AI to deliver seamless and accurate responses.

## 🚀 Key Features
* **Bharat AI:** An advanced reasoning assistant for answering complex text-based queries.
* **Lok-Sevak:** A dedicated portal for document analysis (PDFs/Images) and assistance with government schemes.
* **Multimodal Input Handling:** Process both text and documents (PDF, JPG, PNG) seamlessly.
* **Smart History Tracking:** Built-in SQLite database to track and save user interactions securely.
* **Secure Architecture:** Environment-variable-based API key management for maximum security.

## 💻 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Apple/OpenAI-inspired minimalist UI)
* **Backend:** Python, FastAPI
* **AI Model:** Google Gemini (gemini-3.6-flash) with Fallback Logic
* **Database:** SQLite3
